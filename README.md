# English Daily — B2 → C1 (60 days)

Static learning app. No backend, no paid API.

## Run
Open `index.html` directly, or serve the folder with any static server.

## Deploy free
- GitHub Pages: push these files to a repo and enable Pages from the root.
- Vercel/Netlify: import the repo as a static site.

## Features
- 60-day curriculum
- B2→C1 vocabulary with IPA, Vietnamese meaning and examples
- Natural phrases
- Grammar refresh
- Daily quiz
- Flashcards with simple spaced repetition
- 20-question cumulative Mini Test
- XP, streak, progress tracking
- Export/import local progress
- No speaking recorder

Content is original and uses CEFR-style topic coverage inspired by common B2/C1 learning frameworks.
